# Präsentationen

## AI-Strategie und Enterprise-AI-Portfolio

`ai-strategy-portfolio.html` direkt im Browser öffnen. Kein Installieren oder Server nötig.

14 Hauptfolien / 20 Minuten, 5 Anhangsfolien, 16:9 Full HD (1920×1080), skaliert auf kleinere Displays. Unternehmensvariante über Auswahl wechseln. Sprechernotizen und Quellen sind integriert. Pfeiltasten/PageUp/PageDown navigieren, Home/End springen; Folienauswahl und Buttons funktionieren per Tastatur. In einem Steuerelement gelten dessen native Tasten. Drucken/PDF exportiert alle Folien der gewählten Variante. Browser-Kopf-/Fußzeilen für PDF deaktivieren.

Fachlicher Review-Entwurf: Quellenstatus im Anhang beachten. Wissenschaftliche Metadaten und ausgewählte Abstracts sowie die aktuelle Praxisumfrage wurden geprüft; mehrere Volltexte und Framework-Primärseiten sind noch offen. Keine vollständige wissenschaftliche Methodenvalidierung, DAX-spezifische Marktstudie oder Compliance-Prüfung behauptet.
