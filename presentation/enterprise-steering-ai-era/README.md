# Enterprise steering in the AI era

An English, five-slide thought-leadership deck for a management discussion about strategy, funding, portfolio trade-offs, delegated decisions and lifecycle evidence.

## Open

Open `index.html` directly in a modern browser. The presentation is self-contained and works from `file://`; it needs no server, package installation or internet connection. External citations open their original source only when selected and when a network is available.

## Navigate

- `ArrowRight`, `PageDown` or the next button: next slide
- `ArrowLeft`, `PageUp` or the previous button: previous slide
- `Home` / `End`: first / last slide
- `N`: show or hide presenter notes
- `F`: request or leave fullscreen
- `Escape`: close presenter notes

The URL hash records the current slide, for example `#slide-3`.

## Presenter notes

Press `N` or use the Notes button. Notes contain the interpretation limits, detailed explanation, discussion question and transition supplied for each slide. They are not included in print output.

## Print or export to PDF

Use the browser's Print command and select landscape orientation, 100% scale, no margins and background graphics. Print CSS places all five slides in order, one slide per 16:9 page. Chromium-based browsers generally honour the declared `13.333in × 7.5in` page size; other browsers may fall back to their configured landscape paper size and add margins.

## Known limitations

- Fullscreen depends on browser permissions and may be unavailable for a local file. The presentation remains usable when a request is rejected.
- The deck uses system fonts, so small typographic differences can occur across operating systems.
- External source links require network access; all slide content remains available offline.
- The source base is focused and is not a systematic literature review. See `sources.md` for evidence boundaries.
