# CHG-004 — Interaktive GitHub-Pages-Demo

REQ-004 und ADR-004.

Neu: statischer Next.js-Export für den Repository-Unterpfad, sichtbarer Pages-Browsermodus, validierte synthetische Seedakten, `localStorage`-Persistenz, neue Akten und clientseitiger Markdown-Download. Der lokale Node.js-/SQLite-Modus bleibt erhalten und wird nicht durch einen stillen Fallback ersetzt.

Deployment: `.github/workflows/pages.yml` nutzt Node.js 24, Frozen-Install, Typecheck, Tests, statischen Build, Pages-Artefakt und die offiziellen GitHub-Actions. Berechtigungen sind auf Repository-Lesen, Pages-Schreiben und OIDC-Token begrenzt.

Prüfungen: Typecheck PASS; 3 Backendtests PASS; normaler Build PASS; statischer Export PASS; echte Browserreise unter `/AI-Strategy_Governance_Roadmap/` PASS; keine `/api`-Netzwerkanfrage; Desktop/Mobile-Sichtprüfung PASS. Details docs/qa/REQ-004.md.

Grenzen: öffentlicher Demo-Client, Daten nur im Browserprofil, keine Teamfreigabe, serverseitige Autorisierung, Sicherung oder echten Kundendaten. Öffentliche GitHub-URL erst nach Workflow-Ausführung extern verifiziert.
